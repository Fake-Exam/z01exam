# Intégrer tes fichiers Markdown

1. Ajoute tes 34 leçons Markdown dans ce dossier (ex. `lesson-01.md`, `lesson-02.md`, etc.).
2. Mets à jour `learning-content/manifest.json` :
   - Renseigne chaque leçon dans le tableau `lessons` avec `id`, `title`, `path`.
   - `path` est un chemin relatif (ex. `learning-content/lesson-01.md`).
3. Active le mode Learning via le switch : les leçons seront chargées et listées automatiquement.
